# جُنودالزهراء — نسخه نهایی آماده استقرار

وب‌سایت RTL و واکنش‌گرا برای هیئت فرهنگی جهادی جُنودالزهراء، با Next.js + Prisma + PostgreSQL.

## بخش‌ها
- معرفی هیئت، فعالیت‌ها و گالری
- محتوای روزانه
- قرآن و ادعیه/زیارات
- مداحی و متن مداحی
- احکام با تفکیک سه مرجع و نگهداری منبع/تاریخ بررسی
- نهج‌البلاغه و صحیفه سجادیه
- شهدا و محتوای فرهنگی
- تقویم و اوقات شرعی
- همکاری و کمک
- منابع و سیاست اعتبار/مجوز
- پنل مدیریت محتوا

## راه‌اندازی محلی
```bash
cp .env.example .env
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

## متغیرهای مهم
`DATABASE_URL`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `CRON_SECRET`, `SITE_URL`

`SESSION_SECRET` باید یک مقدار تصادفی و حداقل ۳۲ کاراکتری باشد. رمز مدیر نیز باید قوی و خارج از مخزن نگهداری شود.

## بررسی قبل از انتشار
```bash
npm run typecheck
npm run check:content
npm run build
```

## استقرار
برای محیط production، migrationها را با `prisma migrate deploy` اجرا کنید و آن را در CI/CD قرار دهید؛ اجرای migration توسعه‌ای روی production مناسب نیست. مستندات رسمی Prisma همین تفکیک را توصیه می‌کند. citeturn0search3turn0search7

Next.js برای استقرار production نیاز به build و سپس اجرای سرور production دارد؛ Vercel نیز مسیر رسمی و ساده‌ای برای استقرار Next.js ارائه می‌کند. citeturn0search12turn0search13

## سیاست محتوای خودکار
هیچ فتوای شرعی یا محتوای دارای حق نشر نباید توسط مدل به‌عنوان «منبع اصلی» ساخته شود. محتوای خودکار فقط از منابع مجاز و پس از ثبت منبع/مجوز وارد شود. کانال ایتا به‌صورت پیش‌فرض نیازمند بررسی مجوز است.
