# نسخه V3 — راه‌اندازی عملیاتی

## 1. محیط
- PostgreSQL بسازید و `DATABASE_URL` را تنظیم کنید.
- `ADMIN_PASSWORD` را به یک رمز قوی تغییر دهید.
- `SESSION_SECRET` را یک مقدار تصادفی طولانی قرار دهید.
- دامنه `jonod.alzahraa.313` را به سرور متصل کنید.

## 2. دیتابیس
```bash
npm install
npx prisma generate
npm run db:push
npm run db:seed
```

## 3. اجرا
```bash
npm run build
npm start
```

## 4. مدیریت
`/admin/login` برای ورود مدیر است. پنل `/admin` آمار و مدیریت محتوای `/admin/content` را ارائه می‌کند.

## 5. احکام
بانک `FiqhAnswer` فقط باید با پاسخ‌های مستند و لینک منبع پر شود. موتور جست‌وجو صرفاً محتوای ذخیره‌شده را بازیابی می‌کند و نباید به‌عنوان تولیدکننده فتوا استفاده شود.

## 6. بروزرسانی خودکار
Cron موجود در `/api/cron` باید در محیط میزبانی به‌صورت زمان‌بندی‌شده فراخوانی شود. برای هر منبع خارجی قبل از واردسازی، وضعیت مجوز انتشار بررسی شود.
